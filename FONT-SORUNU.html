Font ayarı neden sadece ana sayfada çalışıyor?

mooncrown04/cloudstream · master Kotlin / Compose · kök neden analizi + düzeltme planı

Kısa cevap

Font seçimi hiçbir yerde kullanılmıyor. Ayarlar ekranında fontu seçiyorsun, tercih (app_font_key) kaydediliyor, sonra activity.recreate() çağrılıyor — ama getAppFontFamily() fonksiyonunu tek bir satır bile çağırmıyor. Ana sayfada gördüğün font, seçtiğin font değil; AppTextViewStyle içindeki sabit Google Sans (Product Sans). Yani her yer zaten "orijinal font"ta.

Kanıt: arama sonuçları

Ne arandıBulunan
getAppFontFamily çağrısıYalnızca kendi tanımı — hiç çağrı yok
settings.ui.appFont okumasıYalnızca ayar ekranındaki preference = bağlantısı
loadAppFont() / perfToFont()Tanımlı ama hiç kullanılmıyor
CloudStreamTheme(fontFamily = …)Parametre var, hiçbir çağrıda verilmiyor (default null)
FontOverlay stilleri (styles.xml)Tanımlı, loadThemes() içinde uygulanıyor — ama Compose'u etkilemiyor

Mimari: nerede kırılıyor

Uygulamada iki ayrı render yolu var. Font ikisinde de farklı davranıyor:

ÇALIŞIR
XML/View ekranları — loadThemes() → theme.applyStyle(GothamFontOverlay). android:fontFamily ve textAppearanceListItem geçersiz kılınır, TextView'ler yeni fontu alır.
ÇALIŞMAZ
Compose ekranları — Ayarlar menüsü (SettingsFragmentScreen, SettingsUIScreen), diyaloglar, altyazı ekranları. Bunlar createComposeView() ile açılıyor ve orada CloudStreamTheme(...) çağrılırken fontFamily parametresi hiç verilmiyor.

Kırılma noktası — ComposeFragment.kt

CloudStreamTheme(
    mode = perfToMode(mode),
    primaryColor = perfToColor(primaryColor),
    // ❌ fontFamily = ... yok  →  Theme.kt'de null  →  Typography() varsayılan font
) {

Theme.kt tarafı zaten hazır

@Composable
fun CloudStreamTheme(
    mode: CloudStreamThemeMode = CloudStreamThemeMode.FollowSystem,
    primaryColor: CloudStreamPrimaryColor = CloudStreamPrimaryColor.NORMAL,
    fontFamily: FontFamily? = null,          // ✅ hazır, sadece beslenmiyor
    content: @Composable () -> Unit,
) {
    val typography = getDynamicTypography(fontFamily)   // 15 text style'ın hepsini değiştirir
    MaterialTheme(colorScheme = …, typography = typography, content = content)
}

İkinci sorun: anahtar tutarsızlığı

SettingsUI.kt içindeki eski diyalog R.string.app_font_key ile okuyup yazıyor, Compose tarafı ise settings.ui.appFont üzerinden aynı anahtarı okuyor — burada sorun yok. Ama perfToFont() yalnızca 5 fontu tanıyor (StixGeneral, Maybach, Perfume, Naxmos, Gotham sessizce "Default"a düşüyor). Font listesi üç ayrı yerde tekrar ediyor: FontUtils.kt, SettingsUIScreen.kt, SettingsUI.kt, artı styles.xml içindeki 10 overlay. Yeni font eklemek 4 dosyayı elle düzenlemek demek.

Düzeltme planı

1 · Tek kaynak: font haritası

app/src/main/java/com/lagradost/cloudstream3/utils/FontUtils.kt

  • Font anahtarı → FontFamily eşlemesi burada tek yerde dursun.
  • rememberAppFontFamily(): tercihi reaktif okur (collectAsState), böylece recreate() beklemeden değişir.
  • Her Compose girişinde kullanılmak üzere sarmalayıcı sağlar.

2 · Kök ComposeView'a fontu bağla

shared/src/androidMain/.../compose/ComposeFragment.kt

val settings = rememberAppSettings()
val mode by settings.ui.theme.collectAsState()
val primaryColor by settings.ui.primaryColor.collectAsState()
val fontKey by settings.ui.appFont.collectAsState()      // ➕

CloudStreamTheme(
    mode = perfToMode(mode),
    primaryColor = perfToColor(primaryColor),
    fontFamily = appFontFamilyFromKey(fontKey),           // ➕
) { … }

Bu tek değişiklik ayarlar ekranlarının, diyalogların ve altyazı ekranlarının tamamını kapsar — hepsi BaseComposeFragment → createComposeView() üzerinden geçiyor.

3 · Diyaloglar ve ayrı pencereler

Dialog.kt içindeki ActionDialog / SingleSelectDialog kendi AlertDialog'unu açıyor; Android'de diyalog yeni bir pencere olduğu için üstteki MaterialTheme taşınmaz. Bunları da CloudStreamTheme(fontFamily = …) ile sarmalamak gerekiyor (veya LocalAppFontFamily composition local'ini okuyup MaterialTheme.typography üzerinden fontu geçirmek).

4 · XML tarafı ile hizalama

  • styles.xml içindeki 10 × 3 overlay stilini tek bir parametreli FontOverlay ailesine indirmek mümkün; şu an 30+ stil bloğu var.
  • perfToFont() eksik fontları tanısın ya da tamamen kaldırılıp tek haritaya bağlansın.

5 · Bonus: yeniden başlatma ihtiyacını kaldır

settings.ui.appFont.set(...) sonrası activity.recreate() çağrısı, tercih reaktif okunduğunda gereksiz kalır — font anında değişir.

Yazılan ilk dosya

app/src/main/java/com/lagradost/cloudstream3/utils/FontUtils.kt — mevcut getAppFontFamily korunarak genişletildi:

fun getAppFontFamily(fontKey: String?): FontFamily?   // 10 font, "Default" → null

@Composable
fun rememberAppFontFamily(): FontFamily?              // reaktif okuma

@Composable
fun AppFontTheme(fontFamily = rememberAppFontFamily(), content)
